# cpp-legacy

This is the original C++/Qt6/CMake scaffold for Calliope, generated by Qt Creator
before the project moved to PySide6 + `uv` (see the root `AGENTS.md` and `README.md`).

It is kept for reference only:
- Not built or tested as part of the current project.
- Not maintained going forward.
- Safe to delete once it's no longer useful as a reference.
